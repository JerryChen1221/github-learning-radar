# 网页图文交付

仅在用户明确要求把文章放到指定页面时进入。不要硬编码某个企业网站、文章 ID 或编辑器选择器；先使用当前环境提供的浏览器能力，读取其最新操作说明。

## 读取目标与保护现有内容

优先复用用户指定页面。只读检查登录状态、现有正文、标题、富文本或 Markdown 模式、图片/附件入口与保存/发布按钮。不要重载有未保存内容的页面，也不要未经确认覆盖已有文章。

编辑前本地保留整理后的文章、SVG 和兼容图。用户已在页面写了内容时以其当前内容为准进行修改，不拿旧本地副本整篇覆盖。

## 先分清填写、保存和发布

- 用户要求填写编辑页不等于授权发布。按当前工具的确认政策，在实际提交草稿、修改公开文章或发布前取得对应确认。
- **“预览”也可能自动保存并生成文章记录。** 只有已确认是只读操作时才直接打开；不清楚时把它视作可能保存，先告知风险并确认，不能靠点击来试探。
- 如果编辑器输入即自动提交或更新公开内容，须在开始输入前确认。仅因按钮写“草稿”不能推断其可见范围。
- 上传仅限用户授权给该网站的文章附件。图片上传请求不自动包含 Skill ZIP、画像或运行日志。
- 如果平台意外保存，停止后续变更，如实说明发生了什么；只读核实状态，不擅自删除、重新发布或用新文章覆盖。

## 填写正文和图片

使用真实存在的页面控件或正式公开的集成能力。浏览器交互只通过该环境支持的 UI 工具；只读 DOM 检查用于观察，不用注入脚本调用隐藏写接口或直接改编辑器状态。

富文本编辑器优先粘贴整理好的 HTML，Markdown 编辑器使用 Markdown。切换模式可能清空内容；不要为了方便转换而丢失已有编辑。

通过文件选择器/页面上传入口上传已确认的图片。读取页面产生的真实图片地址，匹配文件尺寸或图片内容，替换正文中的本地地址。上传后检查加载成功，避免使用暂存 blob、`file://`、绝对路径或失效相对附件链接。

保留标题、段落层级、表格、代码块与引用。检查 HTML 粘贴后是否丢字、合并代码行、重复标题、漏图或丢链接。读到页面现有的元素以后再定位，不能沿用过期索引或猜未暴露的接口。

## 验证与恢复

- 用页面只读状态和实际截图核对标题、正文关键段落、全部图片、表格、代码块和参考链接。
- 只有收到保存确认、草稿列表状态或可靠页面标识，才能称草稿已保存；文章 ID 或详情页本身不证明已发布或未发布。
- 保存后重新打开核对须在已确认保存且不会丢失内容时进行。不要用反复重载来“验证”正在编辑的草稿。
- 页面卡住时先读故障说明和当前状态；必要时用一个新标签页只读核查已经观察到的记录 URL。不要重复点提交，不遍历猜测 ID，不靠另建文章重试保存。
- 出现登录、验证码、权限或网站故障，交付本地稿并说明具体阻碍；不要把尝试动作说成成功。

结束时记录实际网站 URL、交付状态、未完成步骤和截图位置。把截图保存到工作区并在回复直接展示；保留结果或待确认标签页。默认不点击发布。若用户明确要求发布，仍按工具政策在动作时确认并核实发布结果。
